Data Deletion

How to request deletion of your EverywherePoster account data and any connected Facebook, Instagram, or Threads data handled by the service.

Delete Your EverywherePoster Data

To request deletion of your account or data, email arundelkramer@gmail.com and include enough information for us to identify your account.

Delete Through Meta

If you connected EverywherePoster through Facebook, Instagram, or Threads, you can also remove the app from Meta and submit a deletion request there.

  1. Open Facebook and go to Settings & Privacy then Settings.
  2. Open Apps and Websites.
  3. Remove EverywherePoster.
  4. Use the Meta deletion request flow if it is shown.

What Happens Next

  • We remove matching connected Meta channel records and stored access credentials from EverywherePoster.
  • We keep a confirmation code and status record for the request for a limited time so the request can be tracked.
  • Data stored directly by Meta is controlled by Meta and must also be managed in your Meta account settings.

Request Status

Meta callback requests return a status URL and confirmation code. If you have a confirmation code, the status page format is:

/api/public/meta/data-deletion/status?code=<confirmation_code>

Contact

Questions about deletion requests can be sent to arundelkramer@gmail.com.
